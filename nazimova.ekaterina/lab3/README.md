# Лабораторная работа 3

## Задание

Вариант 36

Реализуйте функцию findMaxSubarraySum(arr, n), которая находит максимальную
сумму подмассива длины n.

## Реализация

Функция findMaxSubarraySum(arr, n) возвращает максимальную сумму среди всех
подмассивов длины n, не изменяя исходный массив и работая синхронно. Алгоритм
использует метод скользящего окна: сначала вычисляется сумма первых n элементов,
которая принимается за текущий и максимальный результат, затем окно
последовательно сдвигается вправо на один элемент — из текущей суммы вычитается
элемент, покидающий окно, и прибавляется элемент, входящий в него. После каждого
сдвига текущая сумма сравнивается с максимальной, благодаря чему за один проход
по массиву находится искомое значение за линейное время O(arr.length).

Граничные случаи обрабатываются корректно: при пустом массиве, n <= 0 или если
размер окна n превышает длину массива, возвращается null, так как подмассив
требуемой длины составить невозможно. Функция также выбрасывает TypeError при
передаче невалидных типов аргументов или некорректных элементов массива.
