# Лабораторная работа 2

## Задание

Вариант 36

Реализуйте функцию reverseWords(str), которая переворачивает слова в строке,
сохраняя их порядок (например, reverseWords("Hello world") → "olleH dlrow").

## Реализация

Функция reverseWords принимает строку и возвращает новую строку, в которой
каждое слово перевёрнуто посимвольно, но порядок слов остаётся прежним. Она
является чистой, выполнится синхронно и не изменяет исходные данные. В начале
алгоритм проверяет, является ли аргумент строкой, и при несоответствии типа
выбрасывает TypeError. Затем через метод split(' ') строка разбивается на массив
слов, каждое слово переворачивается с помощью split('').reverse().join(''), а
результат собирается обратно через join(' '). Решение устойчиво к граничным
случаям. Пустая строка возвращается без изменений, строка из одного слова
корректно переворачивается целиком, а несколько подряд идущих пробелов
сохраняются на своих местах как пустые слова. При передаче строки с большим
количеством слов динамический перебор через map отработает корректно без падения
в ошибку.
