# Лабораторная работа 1

## Задание

Вариант 36

Задача 1. Создать таблицу с данными о продажах за месяц. Таблица должна иметь
три столбца — «Продукт», «Продано», «Выручка» и пять рядов с данными. В футере
таблицы необходимо отобразить общую сумму проданных товаров и общую выручку. При
создании таблицы необходимо использовать соответствующие семантические теги —
table, thead, tbody, tfoot и другие. Фон у четных строк должен быть светло-серым
(#f2f2f2), а у нечетных — белым (#ffffff). Ряд таблицы при наведении курсора
должен выделяться более темным серым цветом (#d3d3d3).

## Реализация

Разметка страницы выполнена с использованием семантических тегов для таблиц:
table, caption, thead, tbody, tfoot, tr, th, td. Применены атрибуты доступности
scope="col" и scope="row".

Стилизация выполнена в отдельном файле styles.css без использования
идентификаторов и inline-стилей. Чередование фонового цвета четных (#f2f2f2) и
нечетных (#ffffff) строк реализовано с помощью псевдоклассов :nth-child. Для
подсветки активной строки при наведении применен псевдокласс :hover с цветом
фона #d3d3d3.

## Запуск

Откройте index.html в браузере.
