# Лабораторная работа 3

## Задание

Реализовать функцию countOccurrences, которая подсчитывает количество появлений
каждого элемента массива и возвращает объект со строковыми ключами и
соответствующими счётчиками.

## Реализация

Функция countOccurrences перебирает элементы массива, преобразует каждый элемент
в строку и увеличивает счётчик для соответствующего ключа. Результат
возвращается в виде объекта.

## Запуск

Функция экспортируется как именованный ES module export из файла solution.js.
