# Лабораторная работа 2

## Задание

Реализовать функцию hexToRgb, преобразующую HEX-цвет формата `#RRGGBB` в строку
формата rgb(R, G, B).

## Реализация

Функция hexToRgb выделяет красную, зелёную и синюю составляющие HEX-цвета,
преобразует их из шестнадцатеричной системы в десятичные числа и возвращает
строку rgb(R, G, B). Функция экспортируется как именованный ES module export из
файла solution.js.

## Запуск

Функция экспортируется как именованный ES module export из файла solution.js.
