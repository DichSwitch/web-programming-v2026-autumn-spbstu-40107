# Gadget Hub

Интернет-магазин гаджетов. Курсовой проект по веб-разработке.

## Структура

- `frontend` — React + Vite, React Router;
- `backend` — Node.js + Express;
- База данных не используется (все данные хранятся локально в JSON-файлах внутри
  директории `backend/data`).

## Запуск backend

Бэкенд запускается на порту 8080. Настраивать переменные окружения не нужно.

```bash
cd backend
npm install
node server.js
```
