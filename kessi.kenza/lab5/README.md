# Лабораторная работа 5

## Задание

Вариант «Приложение для заметок». Продвинутый органайзер заметок: создание,
редактирование и удаление заметок; организация заметок в группы по тегам; поиск
по содержимому заметок; фильтрация по группам, тегам и дате. Реализация —
интерактивное React-приложение на JavaScript со сборкой Vite.

## Реализация

Приложение состоит из корневого компонента `App` (`src/App.jsx`), подключаемого
в `src/main.jsx`. Состояние заметок хранится в `useState` и синхронизируется с
`localStorage` через `useEffect`, поэтому заметки восстанавливаются после
перезагрузки страницы.

Структура интерфейса: форма создания и редактирования заметки (заголовок, текст,
теги), панель фильтров (поиск по содержимому, выбор тега, выбор даты), список
заметок с кнопками редактирования и удаления, а также блок группировки заметок
по тегам. Фильтрация выполняется мемоизированным селектором `filteredNotes`:
применяются поисковый запрос, фильтр по тегу и фильтр по дате одновременно.
Список уникальных тегов для фильтра и групп вычисляется через `Set`. Стили — в
`src/styles.css`, классы в kebab-case.

## Запуск

Локально: `cd surname.name/lab5`, затем `npm install` и `npm run dev` — страница
будет доступна по адресу, который выведет Vite. Сборка: `npm run build`.
Проверка перед сдачей запускается из корня репозитория курса: `npm run format`,
`npm run lint:js`, `npm run lint:css`, `npm run lint:html` для каталога
`surname.name/lab5`.
