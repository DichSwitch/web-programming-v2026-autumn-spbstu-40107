# Лабораторная работа 4

## Задание

Вариант «Товары и категории». Класс `Product` с полями `id` (число), `name`
(строка), `categories` (массив строк) и `price` (число). Методы
`addCategory(category)` и `removeCategory(category)`, геттер `categoryCount`.
Функции над коллекцией товаров: группировка по категориям, список уникальных
категорий, группировка по диапазонам цен, поиск товаров по категории и поиск
товаров с ценой выше заданной.

Интерфейс: карточки товаров, форма добавления товара, добавление и удаление
категорий внутри карточки, асинхронное добавление и удаление через `Promise` +
`setTimeout`, сохранение состояния в `localStorage` с восстановлением после
перезагрузки страницы.

## Реализация

Модель вынесена в `model.js` и не зависит от DOM: класс `Product` и пять
именованных экспортов функций коллекции. Входные массивы не изменяются.

Логика интерфейса находится в `main.js`. Состояние хранится в массиве
`products`, сериализуется в `localStorage` под ключом `products` и
восстанавливается при загрузке. Добавление и удаление товаров и категорий
выполняются через `runAsync`, которая оборачивает действие в `Promise` и
откладывает его через `setTimeout`; после завершения вызывается `render()`,
который перерисовывает список без перезагрузки страницы. Обработчики подписаны
через `addEventListener`, поиск кнопок — через event delegation.

## Запуск

Страница не требует сборки: откройте `index.html` в браузере или подайте каталог
статическим сервером, например `npx serve surname.name/lab4`, так как `main.js`
подключён как ES module.
