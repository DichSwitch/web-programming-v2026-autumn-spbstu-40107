# Лабораторная работа 5

## Задание

1 вариант.

Создать список книг, который будет содержать обложку книги, название, рейтинг,
описание и цену. Над списком книг нужно создать кнопки Название, Цена, Рейтинг,
при нажатии на кнопку она должна выделяться (например, цветом) и добавлять
стрелочку для каждого варианта сортировки (↑, ↓), а книги выводить в
отсортированном виде. Порядок сортировки: по возрастанию, по убыванию, не
задано.

## Реализация

**Компоненты:**

- `App` — корневой компонент: кнопки сортировки, индикатор направления и список
  книг;
- `BookCard` — карточка книги (обложка, название, рейтинг, описание, цена),
  получает книгу через props.

**Состояние**:

- `clickSource` — поле сортировки (`title`, `price`, `rating`);
- `sortState` — направление: `↑` (по возрастанию), `↓` (по убыванию) или пусто
  (без сортировки).

Список книг при каждой отрисовке вычисляется из состояния: копия исходного
массива сортируется по выбранному направлению.

**Сценарии:**

- клик по кнопке «Название», «Цена» или «Рейтинг» включает сортировку по
  возрастанию, кнопка подсвечивается, появляется стрелка ↑;
- повторный клик по той же кнопке переключает на убывание (↓);
- третий клик отключает сортировку: подсветка и стрелка пропадают, книги
  возвращаются в исходный порядок;
- клик по другой кнопке начинает сортировку по новому полю сразу с ↑.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
