# Лабораторная работа 4

## Задание

Вариант 1. 4.1. Создать класс `library` с полями:

- `name` — название библиотеки (строка)
- `books` — массив объектов книг, каждая книга с полями: `title`, `author`,
  `year`, `genre`

Реализовать методы:

- `addBook(book)` — добавляет книгу в массив `books`
- `removeBook(title)` — удаляет книгу по названию
- геттер `booksCount` — возвращает количество книг в библиотеке

4.2. Дана коллекция библиотек (массив объектов `library`):

- Реализовать функцию, которая группирует все книги по жанру и возвращает объект
  `Map` (ключ — жанр, значение — массив книг)
- Реализовать функцию, возвращающую уникальный список всех авторов из всех
  библиотек
- Реализовать функцию, которая группирует книги по году издания
- Реализовать функцию, которая возвращает список уникальных годов выпуск
- Реализовать функцию, которая возвращает все книги определённого автора

4.3. Реализовать пользовательский интерфейс:

- Список карточек с отображением информации о книге.
- В каждой карточке выводить: `title`, `author`, `year`, `genre` и кнопку
  “Удалить”.
- Кнопка “Добавить книгу” и поля формы для добавления новых книг в библиотеку.
- Кнопка “Добавить библиотеку”, “Удалить библиотеку” и поля формы для добавления
  новых библиотек
- Добавление илиудаление реализовать асинхронным с использованием `Promise` и
  `setTimeout()`. • При изменении списка он должен автоматически обновляться.
- Использовать `local storage` для сохранения текущего списка книг в библиотеке
  при закрытии вкладки

## Реализация

Модель `Library` в `model.js` хранит название библиотеки и массив книг (у каждой
книги есть `title`, `author`, `year`, `genre`). Метод `addBook` добавляет книгу,
`removeBook` удаляет её по названию, геттер `booksCount` возвращает количество
книг. Функции для работы с коллекцией библиотек группируют книги по жанру и по
году издания (возвращают `Map`), возвращают уникальные списки авторов и годов, а
также находят все книги заданного автора.

Интерфейс в `main.js` строится функцией `render()` по массиву библиотек: для
каждой библиотеки создаётся блок с названием и кнопкой удаления, внутри него —
карточки книг с кнопкой «Удалить». Через формы можно добавлять библиотеки и
книги; библиотека для новой книги выбирается в выпадающем списке, который
заполняется автоматически. Все операции добавления и удаления выполняются
асинхронно через `Promise` и `setTimeout()`, после чего список перерисовывается
без перезагрузки страницы.

Состояние сохраняется в `localStorage` и восстанавливается при загрузке
страницы: сохранённые данные снова превращаются в объекты `Library`. Если
сохранённых данных нет, создаётся библиотека «Основная». Последнюю библиотеку
удалить нельзя, чтобы книгам всегда было куда добавляться.

## Запуск

Откройте `index.html` в браузере.
