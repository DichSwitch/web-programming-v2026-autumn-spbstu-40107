# Лабораторная работа 1

## Задание

Создать меню блюд, используя неупорядоченный список по Варианту 6. Ширина списка
400px, элементы разделены сплошной черной линией 1px, вертикальный отступ 16px.

## Реализация

Использована семантическая разметка `ul` и `li`. Для распределения названия
блюда и цены по краям контейнера применен Flexbox
(`justify-content: space-between`).

## Запуск

Открыть `index.html` в браузере.
