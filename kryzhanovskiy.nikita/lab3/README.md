# Лабораторная работа 3

## Задание

Реализовать функцию intersection(arr1, arr2) (вариант 6), которая возвращает
массив общих элементов двух массивов.

## Реализация

Решение оформлено в виде ES-модуля. Для быстрого поиска общих элементов
используется структура данных `Set`, что исключает дублирование и обеспечивает
линейную сложность. Исходные массивы не изменяются.

## Запуск

Запустить скрипт в среде с поддержкой ES-модулей
