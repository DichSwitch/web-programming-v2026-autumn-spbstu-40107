# Лабораторная работа 2

## Задание

Написать функцию isPerfectNumber, проверяющую, является ли число «совершенным»
(сумма делителей равна числу, исключая само число).

## Реализация

Решение оформлено в виде ES-модуля с именованным экспортом функции
`isPerfectNumber`. Для оптимизации вычисления суммы делителей перебор ограничен
значением `Math.sqrt(num)`. На каждом шаге к сумме добавляются оба парных
делителя. Обработаны нецелые числа, отрицательные значения и числа меньше либо
равные 1.

## Запуск

Запустить скрипт в среде с поддержкой ES-модулей
