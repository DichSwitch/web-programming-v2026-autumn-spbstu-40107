# Лабораторная работа 3

## Задание

Реализуйте функцию findMostFrequent(arr), которая возвращает самый часто
встречающийся элемент в массиве.

## Реализация

Функция `findMostFrequent` принимает массив и возвращает элемент, который
встречается в нём чаще всех. Она является чистой, выполняется синхронно и не
изменяет исходный массив. Частоты подсчитываются за один проход по массиву в
структуре `Map`, где ключ — элемент, а значение — число его вхождений. `Map`
сохраняет тип элементов, поэтому функция одинаково корректно работает и с
числами, и со строками, а `1` и `'1'` считаются разными значениями. Затем второй
цикл перебирает `Map` и запоминает элемент с наибольшим счётчиком. Для пустого
массива возвращается `undefined`. Если несколько элементов встречаются одинаково
часто, возвращается тот, который встретился в массиве раньше. Массив из одного
элемента вернёт этот элемент.
